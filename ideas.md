## ChatGPT generated ideas

Here are **10 projects/exercises** that each focus on a key C programming concept, ranging from beginner to intermediate level:

### **1. Hello, World! (Basics & Compilation)**
   - **Concept:** Basic syntax, `printf()`, compiling a C program.  
   - **Task:** Write a program that prints `"Hello, World!"` to the console.  
   - **Skills Learned:** Basic structure of a C program, compiling with `gcc`.

### **2. Simple Calculator (User Input & Arithmetic)**
   - **Concept:** `scanf()`, arithmetic operations, conditionals.  
   - **Task:** Build a calculator that takes two numbers and an operator (`+`, `-`, `*`, `/`) as input and outputs the result.  
   - **Skills Learned:** Handling user input, using arithmetic operators, basic `if` conditions.

### **3. Guess the Number (Loops & Random Numbers)**
   - **Concept:** `while` loops, `rand()`, conditionals.  
   - **Task:** Generate a random number between 1 and 100, and ask the user to guess it. Give hints if the guess is too high or low.  
   - **Skills Learned:** Loops, using `rand()`, conditionals.

### **4. Array Statistics (Arrays & Loops)**
   - **Concept:** Arrays, iteration, finding min/max/average.  
   - **Task:** Ask the user to enter 10 numbers, store them in an array, and calculate the sum, average, max, and min.  
   - **Skills Learned:** Array handling, iteration with loops, basic statistics.

### **5. String Reversal (Strings & Pointers)**
   - **Concept:** Character arrays (`char` strings), pointers, loops.  
   - **Task:** Take a string input from the user and print it in reverse order.  
   - **Skills Learned:** String manipulation, pointer arithmetic.

### **6. Dynamic To-Do List (Memory Allocation & Linked Lists)**
   - **Concept:** `malloc()`, `free()`, linked lists.  
   - **Task:** Create a simple command-line to-do list where users can add and remove tasks dynamically.  
   - **Skills Learned:** Dynamic memory management, linked lists, struct usage.

### **7. Tic-Tac-Toe (2D Arrays & Game Logic)**
   - **Concept:** Multi-dimensional arrays, functions, game loops.  
   - **Task:** Implement a text-based Tic-Tac-Toe game where two players take turns entering their moves.  
   - **Skills Learned:** 2D arrays, game logic, function design.

### **8. File Reader (File Handling)**
   - **Concept:** `fopen()`, `fgets()`, `fclose()`.  
   - **Task:** Create a program that reads a text file and prints its contents.  
   - **Skills Learned:** File I/O, working with file pointers.

### **9. Bank Account System (Structs & Functions)**
   - **Concept:** Structs, function design, user input handling.  
   - **Task:** Simulate a simple banking system where users can create an account, deposit/withdraw money, and check their balance.  
   - **Skills Learned:** Structs, function-based program structure.

### **10. Multi-Threaded Counter (Threads & Synchronization)**
   - **Concept:** `pthread`, concurrency.  
   - **Task:** Create a program where multiple threads increment a shared counter.  
   - **Skills Learned:** Threads, synchronization (mutex locks).
